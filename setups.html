Zone Scorecard / Setups board

What the indicator is watching.

Every symbol with a Jay S&D alert reports its two target zones on each bar close, scored on the six checks. A setup is valid at the score you set in the indicator (14 by default). Suggestions only. Score it on the sheet and wait for the retest.

Connect a symbol

  1. Open the symbol on a 1H chart with Jay S&D on it. The indicator scores the Low timeframe targets of your style regardless of the chart timeframe, and a 1H chart makes the alert run every hour.
  2. Create an alert: Condition Jay S&D, then Any alert() function call. Options: Once per bar close. Expiration: open ended.
  3. Notifications: tick Webhook URL and paste https://zone-scorecard.vercel.app/api/setup-alert. Leave the message as it is.
  4. Repeat for each symbol in your watchlist. One alert per symbol.

Only TradingView's own webhook servers are accepted. If you set a SCAN_SECRET in Vercel, add ?key=YOUR_SECRET to the URL instead. The board stores only the latest report per symbol and side, plus a short history.
